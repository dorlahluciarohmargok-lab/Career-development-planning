## 项目简介

本项目致力于帮助职场人和求职者：

- 🗺️ **明确方向** — 了解不同职业路径的成长阶梯
- 📚 **高效学习** — 筛选最有价值的学习资源
- 🎯 **备战面试** — 掌握高频题目与面试技巧
- 💼 **规划未来** — 制定个人职业发展蓝图

## 快速开始

### 在线阅读（推荐）

直接浏览 [`docs/`](./docs/) 目录，从 [docs/index.md](./docs/index.md) 开始探索。

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/dorlahluciarohmargok-lab/Career-development-planning.git
cd Career-development-planning

# 安装依赖（可选，用于 Markdown lint）
npm install

# 检查文档格式
npm run lint
```

## 贡献指南

欢迎任何形式的贡献！🎉

### 如何贡献

1. **Fork** 本仓库
2. 创建特性分支：`git checkout -b feature/add-devops-role`
3. 提交更改：`git commit -m 'docs: add DevOps engineer career path'`
4. 推送分支：`git push origin feature/add-devops-role`
5. 发起 **Pull Request**

### 贡献方向

- 📝 新增岗位文档（DevOps、UI/UX 设计师、运营等）
- 🔍 补充面试真题与经验
- 📚 推荐优质学习资源
- 🐛 修正错误信息
- 🌍 内容翻译（英文版）

### Commit 规范

```
feat:  新增功能或内容
docs:  文档更新
fix:   修复错误
style: 格式调整（不影响内容）
```
