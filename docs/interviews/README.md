## 面试流程概述

```
投递简历 → 简历筛选 → HR 初筛电话 → 技术/专业面试（1–4 轮）→ HR 终面 → Offer
```

### 大厂典型面试轮次

| 公司类型 | 轮次 | 形式 |
|---------|------|------|
| 国内大厂（BAT、字节等） | 3–5 轮 | 技术面 + HR 面 |
| 外企（FAANG） | 4–6 轮 | Phone Screen + Onsite |
| 中小公司 | 2–3 轮 | 技术面 + CEO/HR 面 |

## 简历准备

### 简历原则
- **一页纸原则**（工作经验 < 5 年）
- 使用 **STAR 法则** 描述项目经历
- 量化成果（如：将接口响应时间从 500ms 降至 80ms）
- ATS 友好格式（避免花哨排版，使用关键词）

### 简历模板结构
```
姓名 | 联系方式 | GitHub | LinkedIn

教育背景
  学校 | 专业 | 时间 | GPA（可选）

工作/实习经历
  公司 | 职位 | 时间
  • 用动词开头，量化结果
  • 突出技术栈与贡献

项目经历
  项目名称 | 技术栈 | 链接
  • 背景、你的职责、成果

技能
  编程语言 | 框架 | 工具 | 证书
```

## 产品经理面试题

### 产品设计题
**示例题目：** 为老年人设计一款手机银行 App
**答题框架：**
1. 明确目标用户与使用场景
2. 挖掘核心痛点（移动支付困难、字体小、操作复杂）
3. 提出功能方案（大字模式、语音助手、亲属代操作）
4. 定义成功指标（任务完成率、NPS 分数）
5. 考虑风险（安全性、隐私）

### 数据分析题
**示例题目：** 我们的 App DAU 昨天突然下降了 30%，怎么分析？
**答题思路：**
1. 确认数据准确性（埋点、统计口径）
2. 拆分维度（平台 iOS/Android、地区、用户类型）
3. 对比时间（同比/环比）
4. 排查原因（发版、运营活动、外部事件、竞品）
5. 提出修复/应对方案

### 竞品分析题
**答题维度：**
- 产品定位与目标用户
- 核心功能对比
- 商业模式
- 优劣势总结
- 可借鉴之处

## 数据科学面试题

### SQL 题（必考）
```sql
-- 查找每个部门薪资最高的员工
SELECT department, employee_name, salary
FROM (
  SELECT department, employee_name, salary,
         RANK() OVER (PARTITION BY department ORDER BY salary DESC) as rk
  FROM employees
) t
WHERE rk = 1;
```

**高频考点：**
- GROUP BY + HAVING
- 窗口函数（RANK、ROW_NUMBER、LAG、LEAD）
- 自连接 / 多表 JOIN
- 子查询 vs CTE

### 统计与概率
- 什么是 p-value？如何解释？
- A/B 测试如何设计？样本量如何计算？
- 正态分布、泊松分布的应用场景
- 如何处理数据倾斜？

### 机器学习
- 过拟合与欠拟合如何解决？
- 如何处理类别不平衡数据？（过采样、欠采样、SMOTE）
- 特征选择方法有哪些？
- 随机森林 vs GBDT 的区别？
- 如何评估分类模型？（Precision、Recall、F1、AUC-ROC）

## 行为面试（通用）

### STAR 法则
- **S**ituation：描述背景情境
- **T**ask：你需要完成的任务
- **A**ction：你采取的具体行动
- **R**esult：最终结果与影响

### 高频行为面试题

| 问题类型 | 示例问题 |
|---------|---------|
| 领导力 | 讲一个你在没有职权的情况下推动变化的例子 |
| 冲突处理 | 你与团队成员有分歧时如何解决？ |
| 失败经历 | 讲一次你失败的项目，你学到了什么？ |
| 跨部门协作 | 描述一次你与非技术团队合作的经历 |
| 压力应对 | 如何在截止日期压力下保持工作质量？ |

## Offer 谈判技巧

### 谈判原则
1. **先拿到 Offer，再谈判** — 不要在面试过程中过早暴露期望薪资
2. **了解市场行情** — 参考 levels.fyi、脉脉薪资等
3. **综合比较** — 基本工资 + 奖金 + 股票 + 福利 + 发展空间
4. **书面确认** — 所有承诺要求书面化

### 谈判话术示例
> "非常感谢贵公司的 Offer，我对这个机会非常感兴趣。
> 根据我的市场调研和工作经验，我期望薪资能达到 XX–XX 范围，
> 请问是否有灵活调整的空间？"
