## 🗺️ 通用职业发展框架

```
自我评估 → 目标设定 → 技能规划 → 持续学习 → 实践积累 → 求职/晋升
    ↑_________________________反馈与调整__________________________|
```

### 第一步：自我评估
- 我的优势是什么？
- 我对哪个领域最感兴趣？
- 我的短板在哪里？

### 第二步：目标设定
- 短期目标（6 个月内）：如 拿到第一份实习
- 中期目标（1–3 年）：如 晋升到高级工程师
- 长期目标（5 年以上）：如 成为技术负责人 / 创业

### 第三步：技能规划
- 参考各岗位文档中的「核心技能要求」
- 制定个人学习 Roadmap
- 利用 [学习资源](resources/README.md) 中的课程与书籍

### 第四步：持续学习
- 每天保持学习习惯（哪怕 30 分钟）
- 输出倒逼输入（写博客、做分享）
- 参与开源项目或社区

### 第五步：实践积累
- 做真实项目（个人项目 / 开源贡献 / 实习）
- 建立个人作品集（GitHub / Portfolio）
- 参加黑客马拉松或竞赛

## 💡 职业发展黄金法则

1. **T 型人才模型** — 广泛涉猎（横），深耕专业（竖）
2. **持续输出** — 博客、演讲、开源，建立个人品牌
3. **主动社交** — 维护人脉，加入社区，找到 Mentor
4. **拥抱变化** — 技术迭代快，保持好奇心和学习力
5. **身心健康** — 职业马拉松，可持续发展比冲刺更重要
