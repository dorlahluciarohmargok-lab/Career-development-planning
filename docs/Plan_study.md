## 方向选择

### 你的背景组合

```
物联网专业 + 软件测试经验 + PE经历
        ↓
在 IoT / 智能硬件 / 工业测试 方向极度稀缺

纯嵌入式的人不懂测试体系
```

| 路线 | 适合情况 | 周期 |
|------|---------|------|

| **嵌入式开发**（长期投资） | 家里能支持6~9个月，想做专业对口的事 | 9~12个月 |

### 项目三：嵌入式Linux IoT网关（进阶项目）

**平台**：树莓派4B

**功能实现**

```
├── 串口/I2C采集下位机（STM32）数据
├── Linux多线程处理数据（pthread）
├── MQTT上报到云端（mosquitto库）
├── HTTP REST API本地查询接口（libcurl）
├── SQLite本地存储历史数据
└── 简单Web页面展示数据（可选）
```

**这个项目的价值**

```
把STM32 + FreeRTOS + Linux全串起来
完整IoT链路：传感器 → MCU → 网关 → 云端
体现系统级思维，不只是单片机玩具项目
```

**简历描述**
> 基于Linux开发IoT数据网关，
> 实现STM32下位机数据采集、多线程处理、MQTT云端上报全链路，
> 本地SQLite存储历史数据，REST API提供数据查询服务

## 方向对比与最终建议

### 两个方向完整对比

| 维度 | 测试开发 | 嵌入式开发 |
|------|---------|-----------|
| 学习周期 | 3~4个月 | 9~12个月 |
| 入门难度 | ⭐⭐⭐ 中等 | ⭐⭐⭐⭐ 较难 |
| 与现有测试经验衔接 | ✅ 直接用 | ✅ 质量意识加分 |
| 与物联网专业匹配 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 起步薪资（0~1年） | 12~18K | 10~16K |
| 2年后薪资 | 15~25K | 20~30K |
| 5年后天花板 | 25~35K | 30~50K |
| AI替代风险 | 中 | 极低 |
| 岗位数量 | 多 | 中等 |
| 经济压力 | 小 | 大 |

### 推荐路线

```
路线A（稳健优先）：
现有测试经验 → 3个月补Python+pytest+CI/CD
→ 找测试开发岗，先站稳脚跟
→ 拿到offer后继续学嵌入式
→ 往IoT测试开发 / 嵌入式方向深耕

路线B（长远优先）：
物联网专业背景 → 9个月系统学习STM32+FreeRTOS+Linux
→ 完成三个完整项目
→ 投IoT/智能硬件/工业方向嵌入式岗位
→ 需要有经济缓冲，但长期天花板更高
```

### 目标公司方向

```
智能硬件：小米生态链、海尔智家、涂鸦智能、乐鑫科技
工业IoT：海康威视、大华、汇川技术、台达
新能源：宁德时代、比亚迪、阳光电源
物联网平台：华为云IoT、阿里云IoT、移远通信
通信设备：中兴、烽火、紫光展锐
```

## 一句话总结

> **测试开发是快速止血，3个月能找到工作；**
> **嵌入式是长期投资，9~12个月，但物联网背景让你学得比别人快。**
>
> 无论选哪条路，你的核心竞争力都是：
> **物联网专业 + 测试质量意识 + 硬件理解力**
> 这个组合在IoT赛道是真正的差异化，不是在跟几万人卷同一条路。
>
> **定好方向，每天执行，这是最重要的事。**
