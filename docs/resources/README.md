## 📅 学习路线建议

### 入门阶段（0–6 个月）
1. 选定一门编程语言，系统学习基础
2. 完成 1–2 个完整项目，放到 GitHub
3. 每天坚持刷 1–2 道 LeetCode 简单题

### 进阶阶段（6–18 个月）
1. 深入数据结构与算法（中等难度）
2. 学习系统设计基础
3. 阅读优质技术书籍（每月 1 本）

### 求职冲刺（1–3 个月）
1. 集中刷题（LeetCode Top 100）
2. 模拟面试练习
3. 整理项目亮点，准备 STAR 故事
