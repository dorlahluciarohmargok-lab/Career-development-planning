# 产品经理（Product Manager）

## 职业概述

产品经理负责定义产品愿景、收集用户需求、协调研发与设计团队，推动产品从概念到上线的全流程。是连接用户、业务与技术的核心角色。

---

## 职业发展路径

```
产品实习生 → 初级产品经理（PM）→ 产品经理 → 高级产品经理（Senior PM）
                                                      ↓
                                        产品总监（Director of Product）
                                                      ↓
                                         首席产品官（CPO）
```

---

## 核心能力要求

### 产品思维
- 用户需求挖掘与分析
- 竞品分析
- 产品定位与价值主张
- 数据驱动决策

### 沟通与协作
- 需求文档（PRD）撰写
- 跨部门沟通（研发、设计、运营、市场）
- 项目管理与排期协调
- 向上管理与汇报

### 工具使用
| 类别 | 工具 |
|------|------|
| 原型设计 | Figma、Axure、墨刀 |
| 项目管理 | Jira、Confluence、飞书 |
| 数据分析 | SQL、Excel、神策、Mixpanel |
| 思维导图 | XMind、MindNode |

## 各阶段要求

### 初级产品经理（0–2 年）
- 能独立撰写清晰的 PRD 文档
- 熟练使用原型工具
- 了解敏捷开发流程
- 能独立跟进小功能从立项到上线

### 产品经理（2–5 年）
- 负责完整产品线或核心模块
- 具备独立的数据分析能力
- 能主导用户研究（访谈、问卷、可用性测试）
- 有成功产品案例（DAU/MAU 增长、转化率提升）

### 高级产品经理（5 年以上）
- 制定产品战略与 Roadmap
- 能带领产品团队
- 具备商业敏感度，理解 P&L
- 跨业务线协调资源

## 面试要点

- 产品设计题（为某类用户设计一款 App）
- 数据分析题（DAU 突然下降 20%，如何排查）
- 竞品分析（对比两款同类产品）
- 行为面试（讲一个你主导推动的产品决策）
