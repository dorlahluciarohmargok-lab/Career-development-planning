# 软件开发工程师（Software Developer）

## 职业概述

软件开发工程师负责设计、编写、测试和维护软件系统。根据专注领域，可分为前端、后端、全栈、移动端、嵌入式等方向。

---

## 职业发展路径

```
实习生 → 初级工程师（Junior）→ 中级工程师（Mid）→ 高级工程师（Senior）
                                                         ↓
                                          技术专家（Staff/Principal）
                                                         ↓
                                          技术负责人（Tech Lead / Architect）
```

---

## 核心技能要求

### 基础技能
- **数据结构与算法**：数组、链表、树、图、排序、搜索
- **操作系统**：进程、线程、内存管理、文件系统
- **计算机网络**：HTTP/HTTPS、TCP/IP、DNS、RESTful API
- **数据库**：SQL、NoSQL、索引优化、事务

### 编程语言（按方向选择）
| 方向 | 推荐语言 |
|------|---------|
| 前端 | JavaScript / TypeScript |
| 后端 | Java / Go / Python / Node.js |
| 移动端 | Swift / Kotlin / Flutter |
| 数据 | Python / Scala |

### 工程能力
- 版本控制（Git）
- 单元测试 / 集成测试
- CI/CD 流程
- 代码审查（Code Review）
- 系统设计能力

---

## 各阶段要求

### 初级工程师（0–2 年）
- 能独立完成明确需求的编码任务
- 熟悉基本数据结构与算法
- 了解所在团队的技术栈
- 能编写基本单元测试

### 中级工程师（2–5 年）
- 能独立负责模块级设计与开发
- 熟悉分布式系统基础概念
- 具备 Code Review 能力
- 能排查线上问题

### 高级工程师（5 年以上）
- 负责系统架构设计
- 能跨团队推动技术方案落地
- 具备技术影响力（技术分享、开源贡献）
- Mentor 初中级工程师
