# 数据科学家（Data Scientist）

## 职业概述

数据科学家通过统计分析、机器学习和数据可视化，从海量数据中提取洞察，支撑业务决策。兼具数学、编程和业务理解能力。

---

## 职业发展路径

```
数据分析师（Data Analyst）→ 初级数据科学家 → 数据科学家 → 高级数据科学家
                                                                  ↓
                                               首席数据科学家 / 数据科学总监
                                                                  ↓
                                                    首席数据官（CDO）
```

---

## 核心技能要求

### 数学与统计基础
- 线性代数、微积分、概率论
- 统计推断（假设检验、置信区间）
- 贝叶斯统计

### 编程能力
| 语言/工具 | 用途 |
|----------|------|
| Python | 数据处理、建模（pandas, sklearn, pytorch） |
| R | 统计分析 |
| SQL | 数据查询与清洗 |
| Spark | 大数据处理 |

### 机器学习
- 监督学习：线性回归、决策树、随机森林、XGBoost、神经网络
- 非监督学习：K-Means、PCA、自编码器
- 深度学习：CNN、RNN、Transformer
- 模型评估：AUC、F1、交叉验证

### 数据工程基础
- 数据仓库（Hive、BigQuery、Snowflake）
- ETL 流程
- 特征工程
- 模型部署（MLflow、Docker）

---

## 各阶段要求

### 初级数据科学家（0–2 年）
- 能独立完成数据清洗和基础建模
- 熟练使用 Python/R 进行探索性分析（EDA）
- 能撰写清晰的分析报告
- 理解常用机器学习算法原理

### 数据科学家（2–5 年）
- 能端到端交付机器学习项目
- 具备 A/B 测试设计与分析能力
- 能与业务方有效沟通，转化业务问题为数据问题
- 熟悉模型上线与监控

### 高级数据科学家（5 年以上）
- 主导复杂建模项目和算法创新
- 能指导初中级成员
- 具备跨部门影响力
- 了解业务战略，提供数据驱动的战略建议
